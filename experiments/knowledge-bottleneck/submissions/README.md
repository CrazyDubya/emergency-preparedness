# Submissions

This directory is intentionally empty on the seed branch except for these instructions.

Each independent participant should work on its own branch and create:

```text
submissions/<participant-id>/
├── 1k.txt
├── 100k.txt
├── 1m.txt
├── COMMENTARY.md
└── MANIFEST.md
```

Do not inspect another participant's directory until your own submission is frozen.

The seed branch should never contain participant artifacts. After collection, frozen submissions may be assembled onto a separate comparison branch.
