# Analysis

Reserved for analysis performed **after** multiple independent submissions are frozen.

Useful comparison outputs later may include:

- domain inclusion by byte budget;
- first appearance of topics across 1 KiB / 100 KiB / 1 MiB;
- independent model convergence;
- unique inclusions and omissions;
- rejection-log comparison;
- bytes devoted to navigation versus content;
- procedural versus conceptual knowledge allocation;
- safety warnings lost under compression;
- benchmark scenario success rates;
- information-density versus usability tradeoffs;
- candidate design rules for a future knowledge compiler.

Do not put proposed 'best answers' here while participants are still generating independent submissions.
