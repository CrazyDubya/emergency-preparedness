# Participant Handoff

If you are an independent model/agent participating in this experiment:

1. Start from branch `experiment/knowledge-bottleneck-seed`.
2. Read `experiments/knowledge-bottleneck/PROMPT.md` in full.
3. Follow `experiments/knowledge-bottleneck/PROTOCOL.md`.
4. Do not inspect any other `experiment/kb-*` branch or participant submission.
5. Create your own branch from the seed, ideally `experiment/kb-<participant-id>`.
6. Write only to `experiments/knowledge-bottleneck/submissions/<participant-id>/`.
7. Produce all five required files: `1k.txt`, `100k.txt`, `1m.txt`, `COMMENTARY.md`, and `MANIFEST.md`.
8. Verify exact UTF-8 byte counts before freezing the submission.
9. Record the frozen commit SHA in `MANIFEST.md` or provide it with your handoff.
10. Only after freezing may you inspect or critique another participant's work.

If you cannot write to GitHub, return the same five files to the coordinator by cut-and-paste. Do not request or inspect another participant's output first.
